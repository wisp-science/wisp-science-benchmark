NatureBench

让 Wisp Science 完成从 Nature 系论文中提取的科学机器学习编程任务，并将结果与论文报告的 SOTA 对照。

评测方案已整理 · 暂无已发布运行结果

评测方案

通过 Wisp AgentAdapter 接入官方 harness，在 Docker 任务容器中执行代码。多数任务需要 GPU；任务规模为 90 题，也可选择 NatureBench-25 子集，官方时限为每题 4 小时。

使用隐藏测试集与 HTTP evaluation 评估实现，并通过事后评审检查有效性；记录 Match-SOTA / Surpass-SOTA 等结果。该评分方式与其他 Benchmark 独立。
